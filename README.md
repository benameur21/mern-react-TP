# React TP

## Description
This TP is an introduction to React.js. It explores the basics of React and how to create and display user interface elements using components.

## Objectives
- Understand React basics.
- Discover JSX and components.
- Learn how React renders elements.
- Understand the role of the `root` element.

## Technologies
- React.js
- JavaScript
- JSX
- HTML
- CSS

## Run the Project

```bash
npm install
npm start
```
